# Clínica Salud+

Aplicación Android para reserva de citas médicas.

## Autor

Jose Contreras Cabrera

## Ramas

- `main`: desarrollo base de la aplicación.
- `mejora-ia`: mejora funcional creada a partir de main.

## Requerimientos funcionales

1. Mostrar especialidades y médicos disponibles.
2. Ver el perfil de un médico y agendar una cita.
3. Seleccionar fecha y hora antes de confirmar la reserva.
4. Consultar citas agendadas.
5. Navegar mediante menú lateral.
